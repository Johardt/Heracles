# Heracles editor tutorial

The editor helps you author quest graphs. **Select** moves or edits quests, **Hand** pans the graph, **Add** creates a quest, and **Link** connects a prerequisite to a dependent quest.

Use the minimap to move around a large graph. The grid, snap-to-grid, and icon-size controls help keep new quests aligned and readable.

Quest and chapter context menus contain additional actions. Save sends your draft to the server for acknowledgement. A dirty editor has changes waiting to be saved.

Resetting progress is safe for the current player's progress. Editing a quest definition changes the quest itself, so save only when you intend to update the pack.
